# 成果组件：直接选择学年与点击响应

刘总确认采用方案①：点击学年，在组件内部选择目标学年，选择后回到成果列表。

## 交互与状态

- 顶部学年和底部统计入口各提供 48dp 点击区域。
- 点击顶部展开学年列表；再点顶部收起，收起不改变已选学年。
- 学年按最新到最早排列，标明已选项。点击一项直接设置目标学年并收起。
- 统计与查看全部合为一行，给 250×180dp 的最小规格留出至少一条记录的空间。
- 每个组件分别保留选中学年及展开状态，选择不会修改其他组件或 App 学年偏好。
- 正常切换读取缓存，不重复查询 Room；缓存缺失才回源。
- 画面读取 Glance 的实时实例状态；保存/删除后递增内容版本，使活跃会话重新读取缓存。

## 响应与跳转

- 移除 180ms 延迟和进程级协程任务，状态写入后在 ActionCallback 内直接更新本实例。
- 年份选择传递明确目标值，重复点击同一年不会继续翻年。
- 最终绘制时间受 Glance、系统与启动器调度影响，不承诺逐帧或固定毫秒数的响应。
- 查看全部携带当前学年；App 查询实际数据进行校验，历史学年已删除时回落当前学年。
- 冷启动、已有成果页和重复进入同一年都消费一次性请求；查库期间新的页面选择优先。
- 成果行继续按记录 ID 打开详情。

## 验收

1. 展开、收起不跳 App，选择后标题、统计与列表指向同一学年。
2. 重复选择同一年不翻年，快速操作后不回跳。
3. 两个组件分别选不同学年，互不影响。
4. 查看全部的冷启动、已有成果页及同一年重复进入均正确；旋转屏幕后不重放旧请求。
5. 记录详情正确；选中学年删除后能够回落。
6. 4×3、4×4 及长名称下，标题和底部均可点，至少显示一条完整记录。

该方案替代旧 PRD/ADR 的箭头与共享学年偏好约定，其余只读成果和主动刷新边界继续有效。

## 2026-10-09 验证结果

- `:app:assembleDebug :app:testDebugUnitTest --offline --no-daemon` 构建成功，14 个测试套件共 102 项全部通过。
- 使用项目专用 T01Spike 模拟器和临时示例记录，实测展开、收起、直接选年、重复选同一年均通过。
- 查看全部的冷启动、已有成果页、页面手动切年后的再次进入均落在组件指定学年；成果行打开了对应记录。
- 在 App 修改示例成果名称并保存，桌面列表在保留所选学年的同时显示新名称。
- 新增第二个组件选择另一个学年，第一个组件的选中值保持不变。
- 删除第二个组件所选历史学年的唯一示例记录后，它回落到当前学年，选择器移除已删除的学年，第一个组件不受影响。
- 模拟器桌面缩短组件后的标题、列表、底部入口可见；系统选择器成功加载静态预览。该启动器的缩小限制未覆盖精确 250×180dp，需要在目标手机继续验收。
- ADB 截图轮询观察到标题变化约 1.1–2.1 秒，包含输入命令、截图传输和软件渲染开销，不作为真机响应时间指标。
- 目标手机上的实际点击速度、快速连点、屏幕旋转和最小尺寸仍需人工验收。
